# Diskolight 🪩

Welcome to **Diskolight**! This is a fast-paced, interactive web application that instantly turns your screen into a high-speed disco strobe light. It is built cleanly using just HTML, CSS, and JavaScript.

## ✨ Features

*   **🚀 Instant Party:** The disco effect starts the moment you load the page.
*   **⚡ High-Speed Strobe:** Uses a rapid 40ms interval with vibrant HSL colors to create an authentic strobe effect.
*   **⏸️ Pause & Play:** Feeling dizzy? Just **tap/click anywhere** on the screen or press the `ESC` key to pause the lights.
*   **▶️ Smooth Resume:** Easily jump right back into the action by clicking the "Resume" button on the sleek popup menu.
*   **📱 Fully Responsive:** Works perfectly on both desktop monitors and mobile screens.

## 🚀 How to Use

Simply search on the web for **[diskolight.vercel.app](https://diskolight.vercel.app)** and use it!
